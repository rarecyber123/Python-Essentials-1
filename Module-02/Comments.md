
# Comments 

> Python mai comments wo remarks ya notes hote hain jo aap apne code mai insanon ke samajhne ke liye likhte hain. Python execution ke dauran comments ko poori tarah ignore kar deta hai, isliye inka program ke output par koi asar nahi padta.

# Comments Kaise Likhte Hain?

- Hash Sign (#): Python mai comment # se shuru hota hai aur us line ke aakhir tak chalta hai.

- Multi-line Comments: Agar multiple lines par comment likhna ho, toh har line ke start mai # lagana hota hai.

# Comments Kyun Aur Kab Use karain?

- ### Code Explain Karne Ke Liye:

   Aap batate hain ke koi specific trick ya logic kaise kaam kar raha hai, ya variable ka kya maksad hai.

- ### Testing Aur Debugging:

   Agar code ka koi hissa filhal run nahi karna ya check karna ho, toh use # se comment out kar ke temporarily disable kiya ja sakta hai.

- ### Aapke Aur Dusron Ke Liye:

  Baad mai jab aap khud ya koi aur aapka code dekhega, toh samajhna bohot aasan ho jata hai.

# Shortcut Trick

> Code editor mai multiple lines ko ek saath comment ya uncomment karne ke liye CTRL + / (Windows) ya CMD + / (Mac) use karein.
