
# Operators aur Expressions 

> Operators wo symbols hote hain jo values par kaam karte hain (jaise + do numbers ko add karta hai). Jab values (literals) aur operators milte hain, to unhe expression kehte hain.

---
# Basic Arithmetic Operators:

- ### Exponentiation (**):

  Power nikalne ke liye. 2 ** 3 ka result 8 hota hai. Pehla operator hai jo right-to-left chalta hai.

- ### Multiplication (*) aur Division (/):

  Division ka result hamesha float (decimal) aaye ga (jaise 6 / 3 ka output 2.0 hoga).

- ### Integer Division (//):

   Isse "Floor Division" bhi kehte hain. Ye decimal part ko hata kar hamesha choti gol value (rounded down) deta hai (jaise 6 // 4 ka output 1 aur -6 // 4 ka output -2 hoga).

- ### Remainder / Modulo (%):

   Division ke baad bacha hua baqi (remainder) nikalta hai (jaise 14 % 4 ka result 2 hai).

- ### Addition (+) aur Subtraction (-):

   Normal aam hisab-kitab ke liye.

  ---
# Unary vs. Binary Operators:

- Binary: Wo operators jo do values par kaam karein (jaise 4 + 5).

- Unary: Wo operator jo sirf ek value par kaam kare, jaise sign change karne ke liye minus (-4).  
  
---
# Operator Priorities :

### 1. High priority: ** (Exponentiation)

### 2. Unary +, -

### 3. *, /, //, %

### 4. Low priority: Binary +, -
