
# print() Function ka Maksad: 

Yeh Python ka sab se bunyadi built-in function hai jo screen par output dikhane ke kaam aata hai.

# Arguments aur Strings:

Text ko quotation marks ("...") ke andar likha jata hai taake Python use code na samjhe balki data ya string ke tor par process kare.

# Newline Character (\n):

String ke andar \n likhne se text agli line par shift ho jata hai.

# Multiple Arguments:

print() mai comma (,) lagakar ek se zyada arguments diye ja sakte hain, jinhe Python space ke sath print karta hai.
