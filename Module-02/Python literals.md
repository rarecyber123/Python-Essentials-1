
# Literals 

> Literals simple words mein wo direct values hain jo aap apne code mein likhte hain. Unki value fixed hoti hai aur wo wahi dikhate hain jo wo hain (jaise 123 ek literal hai, lekin koi variable c literal nahi hai kyunki uski value change ho sakti hai).

---
# Integers (Pura number):

> Bina kisi decimal point ke numbers ko int kehte hain (jaise 12 ya -5). Readability behtar karne ke liye Python mein numbers ke beech _ use kar sakte hain (jaise 11_111_111). Iske ilawa Octal (0o prefix) aur Hexadecimal (0x prefix) systems bhi use hote hain.
