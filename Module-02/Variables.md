
# Variables 

> Python mai variables simple "boxes" ya "containers" ki tarah hotay hain jahan aap data (numbers, text, wagera) store karte hain taake baad mai code mai use kar sakein.

---
# Variable Naming Rules

- Name sirf letters, numbers, aur underscore (_) se mil kar ban sakta hai.

- Name hamesha letter ya underscore (_) se start hona chahiye (number se start nahi ho sakta).

- Python case-sensitive hai: my_var aur My_Var do alag variables hain.

- Reserved keywords (jaise if, for, import) ko variable name ke taur par use nahi kar sakte.

- Style guide (PEP 8) ke mutabiq lowercase words ko underscore se join karna recommended hai (e.g., total_apples).
