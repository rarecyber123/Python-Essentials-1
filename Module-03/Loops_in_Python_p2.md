
# range(start, stop)

> Python start integer se ginti shuru karta hai aur stop - 1 par khatam kar deta hai (yani stop wala number include nahi hota).

## Code Example:

    for i in range(2, 6):
       print(i)

### Output 

    2
    3
    4
    5

- Start = 2: Ginti 2 se shuru hui.

- Stop = 6: Ginti 6 se pehle (yani 5 par) ruk gayi.
