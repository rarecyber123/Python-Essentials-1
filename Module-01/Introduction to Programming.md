# Computer Languages

> Jaise humans ki natural languages (English, Urdu wagera) hoti hain, waise hi machines ki apni language hoti hai jise Machine Language ya Instruction List (IL) kehte hain.

 ### Kisi bhi language mein 4 cheezein hoti hain:

- Alphabet: Standard symbols ya letters.

- Lexis: Dictionary ke words.

- Syntax: Sentences banane ke sahi rules.

- Semantics: Baat ka koi matlab ya sense nikalna.
