
# Python Obtain & Installation

- Linux: Mostly Linux systems par Python 3 pehle se pre-installed hota hai. Terminal par python3 type karke isko check kar sakte hain. Agar na ho, to system ke package manager se install kiya ja sakta hai.

- Windows & macOS: Official website python.org/downloads se latest Python 3 version download kar sakte hain. Windows par setup chalate waqt Add Python 3.x to PATH wale option ko zaroor check karein.

# Syntax Errors aur Troubleshooting

- # Quotes aur Parentheses:

   Hamesha seedhe quotation marks "" istemal karein, fancy/curved quotes Python accept nahi karta. IDLE brackets ke pairs ko highlight karta hai taake galti na ho.

- # Errors ki Pehchan:

  - Closing bracket bhoolne par EOF (End-Of-File) error aata hai.

  - print ka spell galat karne par NameError jaisa Syntax Error milta hai.

  - Traceback Read Karna: Red text galti ki jagah (file name, line number) aur wajah wazeh tor par batata hai, jise dekh kar aap easily code fix kar sakte hain.
